常见问题

需要安装 Node.js 吗？

不需要。免安装包已包含运行所需的 Node.js。请先完整解压，不要直接在压缩包窗口中运行 exe。

我的数据保存在什么地方？

工作区保存在当前 Windows 用户的 %LOCALAPPDATA%\所向\workspace.json。设置中可以导出 JSON 备份。

AI 功能会自动运行吗？

不会。AI 功能需要你自行配置兼容接口，并在界面中主动发起；生成内容可以检查和修改。
