# 所向：类别识别、看板筛选与单页详情设计

## 目标

让类别成为卡片最明显的视觉识别信息，用筛选替代看板说明文字，把卡片详情收敛为一个自然的阅读与局部编辑页面，并修正洞察页中漏斗和停滞项目的表达。

## 已确认设计

- 品牌改为“所向”，英文标语为“ATTENTION, DIRECTED.”。
- 探索标题改为“我准备了解什么？”，创造标题改为“我想要创造什么？”。
- 卡片颜色由类别决定。阶段色仅保留在列顶部；26px 拖拽区使用完整类别色，正文使用白色或极浅底色。
- 看板右上角改为筛选区。类别直接多选，主题通过可搜索的多选菜单选择；同组为“或”，跨组为“且”，支持一键清除。
- 探索板块当前 63 张导入卡片的旧主题执行一次性 AI 重建。每张最多两个主题，优先从受控主题库选择；用户后续新增主题不被反复覆盖。
- 详情不再分“预览 / 编辑”标签页。元信息默认阅读，通过“编辑信息”局部进入编辑；说明默认渲染 Markdown，点击说明区域后局部进入 Markdown 编辑，并可保存或取消。
- 阶段漏斗每一层均为上宽下窄，整体从 Radar 到 Outcome 逐层收窄；数字表示当前阶段数量。
- 停滞项目按探索、创造左右分栏，每项显示标题、类别、主题和停滞天数，并按停滞时间降序排列。

## 主题治理

初始受控主题库以当前内容为依据，包含 AI 与智能体、教育技术、教学设计、学习科学、项目式学习、教师发展、科研与信息检索、写作表达、思维模型、个人成长、注意力与个人系统、科学与自然、社会与文化、设计与创意。AI 可以建议库外主题，但只有用户确认后才纳入正式主题库。

## 安全边界

- 一次性主题迁移只覆盖内置数据中可识别的探索卡片 ID。
- 不改动卡片标题、说明、类别、阶段、时间或历史事件。
- 不覆盖用户后来新增的非内置卡片。
- Markdown 预览继续经过安全过滤。
