# 个人注意力工作台：洞察布局与主题标签编辑设计

日期：2026-08-21  
状态：已确认

## 1. 调整目标

本次调整只解决两件事：让洞察页更直观地呈现当前注意力结构，以及让主题标签可以像标签一样直接增删。它不改变卡片生命周期、WIP、滴答交接或知识沉淀边界。

## 2. 洞察页布局

`BALANCE` 与 `STAGES / NOW` 交换位置：

- `BALANCE` 使用原 `STAGES / NOW` 的顶部通栏位置；
- `STAGES / NOW` 使用原 `BALANCE` 的左侧卡片位置；
- `TOPICS / NOW` 保持在右侧；
- `AGING` 及其他洞察不变。

窄屏下各卡片仍按页面顺序纵向排列。

## 3. STAGES / NOW

### 3.1 含义

继续统计 Radar、Focus、Engage、Outcome & Review 当前各有多少张未归档卡片。它不是历史跳转次数，也不是阶段转化率。

### 3.2 表现

恢复漏斗外形，每个阶段占一层，从上到下依次收窄。每层直接显示阶段名称和当前数量。

漏斗宽度只用于表达生命周期由宽到窄的结构，不表示精确比例；准确值以层内数字为准。每层同时提供可访问名称，方便键盘和辅助阅读工具识别。

## 4. TOPICS / NOW

### 4.1 统计口径

使用环形图替换现有图标卡片。由于一张卡片可以拥有多个主题，图表按“主题标签出现次数”计算占比，而不是按互斥的卡片份额计算。

只统计未归档卡片：

- 展示出现次数最多的 6 个主题；
- 超过 6 个主题时，其余合并为“其他”；
- 图例显示颜色、主题名称和标签出现次数；
- 没有主题时显示现有空状态；
- 图表中心显示主题标签总出现次数，避免把它误读为卡片总数。

环形图扇区、图例颜色和顺序保持一致。窄屏下图表与图例上下排列。

## 5. 主题标签编辑

新建卡片和卡片详情共用同一种编辑方式。

### 5.1 默认状态

- 已有主题显示为圆角标签；
- 标签保留完整文字，不再要求用户输入逗号分隔文本；
- 末尾显示“＋ 添加标签”按钮。

### 5.2 新增

点击“＋ 添加标签”后，在原位置出现输入框：

- 按 Enter 添加当前内容；
- 按 Escape 取消输入；
- 点击输入区外时，有内容则添加，无内容则取消；
- 自动去除首尾空格；
- 与已有标签完全相同的内容不重复添加；
- 添加成功后保持输入状态，便于连续添加多个标签。

### 5.3 删除

- 鼠标悬停已有标签时，右侧出现小叉；
- 点击小叉删除该标签；
- 使用键盘聚焦标签时，小叉同样可见并可操作；
- 详情编辑中的增删仅修改当前草稿，点击“保存修改”后才写入卡片；取消编辑会恢复原标签。

## 6. 验收口径

1. `BALANCE` 位于洞察页顶部通栏，`STAGES / NOW` 位于下方左侧。
2. `STAGES / NOW` 呈漏斗形，依次显示四个活动阶段及当前卡片数。
3. 漏斗数据仍是当前数量，不出现历史跳转或转化率表述。
4. `TOPICS / NOW` 使用完整环形图，展示前 6 个主题及“其他”，图例数据与图表一致。
5. 环形图按主题标签出现次数计算，中心明确显示标签总次数。
6. 新建和编辑卡片时，主题以圆角标签呈现，可通过“＋ 添加标签”连续新增。
7. 已有标签仅在悬停或键盘聚焦时显示删除叉号，点击后从当前编辑草稿删除。
8. 重复主题不会被再次添加；空主题不会被添加。
9. 取消详情编辑不会保存主题改动，保存后重新打开仍能看到修改结果。
10. 洞察页和标签编辑在窄屏下不溢出，鼠标与键盘均可完成主要操作。

## 7. 对原设计的替代

本文档替代《个人注意力工作台：卡片交互、洞察与类别调整设计》中以下两项表现层约定：

- “当前阶段分布使用横向分布条”改为漏斗；
- “当前关注领域使用图标卡片”改为环形图。

其他已经确认的产品规则继续有效。
