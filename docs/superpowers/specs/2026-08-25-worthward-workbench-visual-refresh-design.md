# 所向 · WORTHWARD 工作台视觉改版设计

## 目标

面向已经使用所向的用户，统一工作台、说明页和公开仓库中的品牌表达，提高看板的阅读效率，同时保持现有业务流程、数据结构和交互逻辑不变。

品牌信息：

- 中文名：所向
- 英文名：WORTHWARD
- 标语：Attention, directed.
- 作者：CashewLab
- GitHub：公开仓库 `worthward`，由当前已授权的 GitHub 账户创建

## 设计方向

采用“安静的注意力仪表台”。保留四列看板和用户熟悉的操作方式，减少顶部与卡片中的视觉噪音，让当前问题、阶段和需要行动的内容更突出。

### 视觉系统

- 深绿色用于品牌和主要操作；
- 薄荷绿用于当前选择、积极状态与交互反馈；
- 珊瑚色仅用于 Engage、警告和需要处理的内容；
- 背景、容器与分隔线保持低对比度，不使用大量阴影和装饰；
- 新版圆角同心圆图标作为工作台与说明页的统一 Logo。

## 顶部区域

- 左侧显示新版 Logo、“所向 · WORTHWARD”和 `Attention, directed.`；
- 中部保留“探索、创造、洞察”主导航，当前入口使用薄荷绿标记；
- 右侧保留搜索、归档、设置与“记录想法”；
- “记录想法”使用深绿色背景，是顶部唯一的主要操作；
- Focus 和 Engage 数量不在顶部显示。

## 看板主体

- “我渴望了解什么？”和“我想要创造什么？”继续作为页面主问题，但减少垂直占用；
- 类别与主题筛选整理为横向工具栏，结果数量放在右侧；
- Radar、Focus、Engage、Outcome & Review 四列继续同时展示并支持原有拖动操作；
- 每一列只显示当前卡片数量。Focus 和 Engage 的容量上限属于探索与创造的合计值，不能在单个板块的列标题中呈现；
- 卡片按“标题、类别、主题、最近状态”建立阅读顺序，减少重复边框和弱信息；
- 手机端继续使用横向滑动浏览四列，不改成长纵向列表。

## 其他页面与弹窗

- 洞察页保留现有图表、主题下钻和每周复盘功能，统一卡片间距、标题层级与颜色；
- 归档页强化完成与停止关注两种状态的区分；
- 设置页按工作方式、外部连接、数据管理建立清晰的视觉分组，但不增加“关于所向”区域；
- 详情抽屉、记录窗口、AI 建议、投入确认与每周复盘统一按钮、输入框、标题和提示样式；
- 不改变 AI 必须由用户点击触发并确认后才修改数据的规则。

## 页脚

所有主要页面的内容末尾使用同一简洁页脚，显示：

- 所向 · WORTHWARD
- 作者 CashewLab
- 当前软件版本
- GitHub 公开仓库链接

页脚不固定在视口，不占用看板操作空间。仓库创建后使用真实地址，不保留空链接。

## 说明页同步修改

- “开始使用”按钮改为与页面其他主要操作一致的深绿色；
- 软件特色标题改为“AI 提出聚焦方向建议，由你确认投入方向。”；
- 页脚作者改为 CashewLab；
- GitHub 链接改为新建公开仓库的真实地址。

## GitHub 与回退策略

1. 在任何视觉改版前，检查公开上传范围、运行完整测试并创建当前版本的基线提交；
2. 创建公开仓库 `worthward`，推送基线提交；
3. 完成视觉改版，在本地通过测试与浏览器检查；
4. 将改版作为独立提交推送，使 GitHub 基线提交始终可用于回退；
5. 不上传 `node_modules`、内置 Node 运行环境、构建产物、测试截图、发布压缩包、可执行文件、本机工作区数据或 AI 凭证。

## 验收标准

- 工作台和说明页均显示所向 · WORTHWARD、新版 Logo、CashewLab 和真实 GitHub 链接；
- 顶部不显示 Focus / Engage 数量；各看板列仅显示当前卡片数量；
- 所有原有操作、数据保存、AI、滴答清单、归档、复盘和筛选功能保持可用；
- 桌面端无横向溢出，手机端看板可横向滑动；
- 键盘焦点清晰，减少动画设置继续生效；
- 单元测试、类型检查、构建与浏览器验收全部通过；
- GitHub 上存在可回退的改版前基线提交和独立的视觉改版提交。
