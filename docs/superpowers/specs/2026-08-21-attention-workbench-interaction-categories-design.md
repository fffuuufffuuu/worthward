# 个人注意力工作台：卡片交互、洞察与类别调整设计

日期：2026-08-21  
状态：已确认

## 1. 调整目标

本次调整继续守住工作台的核心边界：工作台只负责选择和管理“什么值得我的注意力”，不承担知识沉淀，也不承担具体任务管理。

因此本次设计遵循三条原则：

1. 卡片详情以阅读和判断为主，编辑是次级行为。
2. 正常推进只需一个明确按钮，自由跳转仍作为备用能力保留。
3. 洞察展示当前注意力结构，不用容易误解的历史转化数据代替现状。

## 2. 卡片详情

### 2.1 默认模式

卡片打开后默认进入“预览”。预览区显示：

- 所属板块；
- 类别；
- 主题标签；
- Markdown 说明；
- 入库时间和进入当前阶段的时间。

预览旁提供“编辑”按钮。点击后进入编辑模式；保存后返回预览。取消编辑时放弃本次尚未保存的修改。

### 2.2 阶段推进

“移动到”下拉框继续保留，用于降级、跳过或自由移动。其右侧增加一个更醒目的下一阶段按钮：

| 当前状态 | 按钮 |
|---|---|
| Radar | 进入 Focus |
| Focus | 进入 Engage |
| Engage | 进入 Outcome & Review |
| Outcome & Review | 完成并归档 |
| Archive | 不显示推进按钮，保留恢复到 Radar |

进入 Focus 或 Engage 时继续执行 WIP 检查。Outcome & Review 的“完成并归档”记为正常归档，不记为 Drop。

### 2.3 进入 Engage

从任意非 Engage 阶段进入 Engage 时，弹窗提供三个操作：

- 取消；
- 仅移入；
- 移入并创建滴答任务。

“仅移入”只改变工作台状态，不产生滴答交接记录。“移入并创建滴答任务”在成功移入后打开滴答任务创建入口，并保存一次不可重复的交接记录。工作台无法确认用户是否在滴答内最终保存，因此界面只显示“已发起创建”。若卡片已有交接记录，第三个按钮显示为已发起状态并禁用，仍可选择“仅移入”。

工作台不追踪滴答任务之后的修改与完成状态。

## 3. 取消投入时间记录

工作台不再提供分钟数或投入时间记录：

- 卡片详情删除“记录投入”；
- 洞察页删除“累计投入”；
- 停滞判断统一使用 Last Touched；
- 系统不再产生新的投入时间记录。

为避免破坏旧备份，旧数据中已经存在的时间记录可以保留，但不再显示、统计或参与判断。

洞察页顶部原“累计投入”位置改为“等待 Review”，显示 Outcome & Review 当前数量。

## 4. 洞察页

### 4.1 当前阶段分布

原“阶段转化”改名为“当前阶段分布”。它展示当前未归档卡片分别处于 Radar、Focus、Engage、Outcome & Review 的数量和占比。

该区域不再展示历史跳转次数、绕过 Focus 次数或转化率。视觉形式改为按实际数量变化的横向分布条，避免固定漏斗宽度造成误解。

### 4.2 当前关注领域

原“最近关注领域”实际统计的是全部未归档卡片，因此改名为“当前关注领域”。每个主题以图标卡片呈现，包含：

- 语义图标；
- 主题名称；
- 卡片数量。

教育、AI、教学工具、写作、成长和沟通等常见主题使用稳定的线性图标；无法匹配的主题使用通用节点图标。图标只辅助识别，不替代主题文字。

真正基于时间窗口的“最近关注”留到积累足够工作台行为数据后再实现。

## 5. 新类别体系

类别描述注意力对象的形态，主题标签描述内容领域。类别为板块内单选，允许暂时未分类，以保持 Capture 足够轻。

### 探索

| 类别 | 范围 |
|---|---|
| 主题 / 问题 | 知识、概念、方法、待研究的问题、机构或工具 |
| 书籍 / 影音 | 书籍、文章、报告、影片、演讲等边界明确的内容 |
| 课程 / 体验 | 课程、讲座、比赛、展览、参访和线下活动 |

### 创造

| 类别 | 范围 |
|---|---|
| 产品 / 项目 | 软件、硬件、工具、系统、实验和研发项目 |
| 写作 / 表达 | 文章、研究、报告、演讲和其他表达产出 |
| 活动 / 组织 | 活动、工作坊、社群和协作组织 |

## 6. 现有数据迁移

现有卡片在载入时迁移，不覆盖标题、说明、主题、阶段或时间信息。

- 已符合新类别的卡片保持不变；
- 探索类中，书名、影片或演讲类条目归入“书籍 / 影音”；课程、比赛和活动类条目归入“课程 / 体验”；其他归入“主题 / 问题”；
- 创造类中，思考与文字产出归入“写作 / 表达”；现有 AI 教学工具与研发事项归入“产品 / 项目”；
- 无法可靠判断的条目保持“未分类”，不猜测；
- 原自由文本类别不再显示。

新建和编辑卡片时，类别只能从当前板块的三个类别中选择。切换板块后，若原类别不属于新板块，则重置为未分类。

## 7. 验收口径

1. 卡片默认显示预览和完整元信息，点击编辑后才能修改。
2. 每个活动阶段都有正确的下一阶段按钮，自由移动仍可使用。
3. 进入 Engage 时三个按钮的行为互不混淆，只有第三个按钮触发滴答入口。
4. WIP 超限确认同时适用于下拉、拖拽和下一阶段按钮。
5. 页面中不再出现投入分钟和累计投入。
6. 洞察展示当前阶段数量，导入卡片也被正确计入。
7. 当前关注领域显示图标、主题和数量，并可在窄屏正常阅读。
8. 新建和编辑只能选择六个新类别或未分类，现有 96 张卡片完成迁移。
9. 原有说明、来源、阶段、WIP、Drop、Spawn、归档和恢复功能不受影响。
