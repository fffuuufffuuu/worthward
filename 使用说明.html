02 · CAPACITY

自带刹车

Focus 与 Engage 有建议在途上限。继续加入之前，你会先看见容量和机会成本；即使任性加入，代价也不会被藏起来。

03 · REVIEW

定期梳理注意力

通过结构化的注意力梳理，重新判断哪些线索值得关注、哪些事项值得投入、哪些成果应该沉淀。

04 · HANDOFF

执行接力棒交给日历

进入投入阶段后，将主任务、检查事项与时间安排交给日历或滴答清单。所向继续管理投入对象，而不是接管日常任务。

05 · LOCAL FIRST

本地优先

卡片与 AI 凭据保存在当前 Windows 用户目录，不随软件文件夹或浏览器缓存一起流转。工作区可随时导出 JSON 备份，分享绿色版也不会带上个人数据。

START IN THREE MINUTES

开始试试，
把第一条线索放进 Radar。

启动这件事很短，真正重要的是先记录，再判断。

完整解压

将压缩包解压到任意文件夹，例如 D:\所向。保持原有目录结构，不要单独移动其中的文件。

双击 Worthward.exe

程序会在后台启动本机服务，并自动打开浏览器。若服务已经运行，只会再次显示当前工作界面。

记录第一条线索

点击右上角“记录想法”，把一件可能值得关注的探索或创造放进 Radar。先记录，不必急着承诺。

创建桌面快捷方式

右键 Worthward.exe，选择“发送到 → 桌面快捷方式”。快捷方式应始终指向解压目录中的可执行文件。

先解压，再运行

不要在压缩包内部直接双击。只有完整目录中的启动程序才能找到随软件附带的运行环境。

FIRST-RUN HELP

第一次使用，
可能遇到的问题。

双击后浏览器没有自动打开怎么办？

等待几秒后，再双击一次 Worthward.exe。如果仍然没有反应，请确认压缩包已经完整解压，并且 Worthward.exe、node、dist、server 仍在同一软件目录结构中。

可以直接从压缩包里双击运行吗？

不可以。压缩包视图不是完整的软件目录，启动器无法稳定找到需要的文件。请先完整解压，再双击 `Worthward.exe`。

移动软件文件夹会丢失卡片吗？

不会。卡片保存在当前 Windows 用户目录，而不是软件文件夹。但桌面快捷方式仍指向旧位置时需要重新创建。

如何备份或换电脑？

在“设置”中导出 JSON。换电脑后启动一份干净绿色版，再从设置导入备份。API 密钥不会包含在 JSON 中，需要单独重新配置。

所向会把本机服务开放给局域网吗？

不会。日常服务固定监听 127.0.0.1，只供当前电脑访问。
